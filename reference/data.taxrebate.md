# tax rebates

tax rebates before tax slab adjustments

tax rebates before tax slab adjustments

## Usage

``` r
data.taxrebate

data.taxrebate_under87A
```

## Format

data.taxrebate: A data frame (11, 6):

- rebate.id:

  rebate identification number

- rebate.code:

  rebate code/short name

- rebate.limit:

  maximum rebate

- tax_regime:

  old or new regime

- financial_year:

  financial year

- rebate.info:

  comments or additional information
