# tax rebates under step 2

tax rebates after tax slab adjustments

## Usage

``` r
data.rebate_on_investments
```

## Format

data.rebate_on_investments: A data frame:

- rebate.id:

  rebate identification number

- rebate.code:

  rebate code/short name

- rebate.limit:

  maximum rebate

- tax_regime:

  old or new regime

- financial_year:

  financial year

- rebate.info:

  comments or additional information
