# tax slabs for both old and new regime

tax slabs for both old and new regime

## Usage

``` r
data.taxslabs
```

## Format

data.taxslabs: A data frame (10, 7):

- slab.id:

  slab identification number

- slab.min:

  slab minimum amount

- slab.max:

  slab maximum amount

- slab.percent:

  tax percentage charged for the slab

- tax_regime:

  old or new regime

- financial_year:

  financial year

- slab.info:

  comments or additional information
