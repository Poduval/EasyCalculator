# EasyCalculator: simple financial calculators for India

A growing collection of easy to use financial calculators for India.
Each calculator takes either a plain value or a data frame (for many
people at once) and returns a transparent, step-by-step result.

## Calculators

- [`tax_payable()`](https://poduval.github.io/EasyCalculator/reference/tax_payable.md):
  income tax under the old and new regimes.

More calculators (GST, loan scheduler) are planned.
